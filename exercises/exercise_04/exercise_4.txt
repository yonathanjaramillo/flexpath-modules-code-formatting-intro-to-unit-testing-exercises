
Exercise 4: Mixing ES Modules and CommonJS

Description: 

Explain why mixing ES Modules and CommonJS modules can lead to issues. 

Provide an example where importing a CommonJS module using 
ES Module syntax causes problems.

Mixing ES Modules and CommonJS can cause problems because they use
different ways to import and export code.

CommonJS uses require() and module.exports.
ES Modules use import and export.

Problem example:

// math.js
module.exports = {
  add: (a, b) => a + b
};

// app.js
import { add } from "./math.js";

This can fail because CommonJS does not provide "add" as an ES Module
named export.

Solution:

Use the same module system in both files.

// math.js
export function add(a, b) {
  return a + b;
}

// app.js
import { add } from "./math.js";

console.log(add(2, 3));
